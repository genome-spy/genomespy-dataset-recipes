  ordinary hg18 gene-name/distance annotations have no separately identified
  restricted clinical track in the source description.

## Interpretation and conditions

The map observations, annotation fields, and authored simulation/selection
contributions retain their distinct terms. This carries forward the Python
project's existing provenance assessment, supported by the source records above.
Use the authoritative manhattanly copy directly; no Plotly code or data
transformation is imported into the CC0 recipe.

Credit Sahir Bhatnagar (2016), HapMap, UCSC, and Vince Forgetta's annotation work.
Publish the two notice artifacts alongside the table and retain this attribution
in the release README. State that association statistics are simulated and that
acquisition does not reproduce the original sampling/annotation pipeline.
The recipe repository's CC0 dedication does not relicense adjacent data.
